## 1. 变更摘要

- 变更一句话说明：将项目技术名从 `fons4ai-knowledge-engine` 调整为 `fons4ai-rag2okf`。
- 本次变更结论：仓库目录、Maven 模块、Spring 服务名、Java 根包和前端包统一采用 Rag2OKF 命名；业务功能标识、领域模型、API、数据结构和 AC 不变。
- 是否建议新建 feature：否，本次只调整既有功能所属项目的技术命名。

## 2. 变更原因

- 用户诉求：采用更有作品辨识度、能表达“源文档/RAG 到 OKF 知识层”技术路径的项目名。
- 业务或技术背景：`fons4ai-rag2okf` 作为仓库技术名更能体现项目特色；最终产品展示名仍应独立设计。
- 不变更的影响：若不统一，后续脚手架可能同时出现 knowledge-engine 与 rag2okf 两套 artifactId、service name 和 package，增加维护成本。
