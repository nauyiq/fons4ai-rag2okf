# CR-006 前后端独立项目与打包边界调整

## 1. 变更摘要

- 变更一句话说明：`fons4ai-rag2okf` 只作为仓库根目录，不是 Maven 或 Node 项目；后端和前端目录分别作为独立项目根构建和打包。
- 本次变更结论：删除根聚合 `pom.xml` 规划；`fons4ai-rag2okf-service` 独立产出 JAR/后端镜像，`fons4ai-rag2okf-ui` 独立产出 `dist/`/Nginx 镜像；生产由 Nginx 同源提供静态资源并反向代理 API。
- 是否建议新建 feature：否。业务需求、AC、领域模型和运行链路不变，只修正构建与交付边界。

## 2. 变更原因

- 用户诉求：仓库根目录不应是 POM 项目，后端目录是后端项目根，前端目录是前端项目根。
- 业务或技术背景：前后端技术栈、构建缓存、发布节奏与回滚单元不同，前端最终由 Nginx 静态托管，不需要被 Maven Reactor 或后端 JAR 绑定。
- 不变更的影响：根聚合 POM 会把仓库目录错误描述成 Maven 项目，后端 POM 还会依赖不存在的聚合父项目，导致独立构建和后期 Nginx 部署边界混乱。
