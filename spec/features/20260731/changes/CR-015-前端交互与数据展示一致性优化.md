# CR-015 前端交互与数据展示一致性优化

> 功能标识：`knowledge-base-document-lifecycle`
> 变更类型：重构
> SDD 等级：`S2`
> 文档状态：正式
> 创建日期：2026-08-07

## 1. 变更摘要

- 变更一句话说明：统一 Rag2OKF 前端的表单提交状态、错误反馈、分页与数据格式、任务轮询、弹窗可访问性和应用导航，使页面反馈真实、局部、可恢复且可键盘操作。
- 本次变更结论：在不修改后端 API、业务状态机和持久化结构的前提下，新增前端交互基础组件与格式化工具，并按认证与设置、模型设置、知识库/文档列表、文档详情和应用外壳分批改造。
- 是否建议新建 feature：否。业务能力和页面集合不变，本次是既有页面的跨模块交互一致性重构。

## 2. 变更原因

- 用户诉求：用户确认按照现有审查建议全部优化前端表单提交、数据渲染格式和页面交互。
- 业务或技术背景：当前页面分别维护 loading、error、success、formatTime 和 formatBytes，导致错误脱离触发表单、提交后整页闪烁、分页总数失真、内部枚举直接暴露、弹窗键盘路径不完整以及导航入口与实际能力不一致。
- 不变更的影响：继续增加页面会放大重复实现和交互漂移；模型密钥取消后未及时清理、轮询持续整页刷新和注册条款静默同意也会形成安全与信任风险。

## 3. 当前状态检查

- 任务规划未完成项：T047～T054，属于 CR-014 数据结构、文件夹和批量上传链路；T058、T059、T061 必须等待相关任务关闭，其他前端基础任务可按依赖执行。
- 历史 CR 未完成项：CR-014/T047～T054；本 CR 不覆盖其后端、DDL 或文件夹业务实现。
- 文档与代码一致性：存在局部差异。T019 已标记完成，但当前页面仍存在重复格式化、局部错误被提升为整页错误、轮询闪烁、原始状态码和失效导航文案；需求说明书的 CR-014 修订记录也尚未补齐。
- 技术设计与当前实现一致性：V4 主题和页面清单已落地，但缺少统一的表单状态、弹窗焦点、分页呈现和后台刷新设计契约。
- 前置问题：无。用户已确认采用审查建议；文档列表相关实现按任务依赖等待 CR-014。

## 4. 影响范围

- 需求影响：新增前端反馈、数据真实性、后台刷新、弹窗、敏感输入和导航可用性验收标准 AC-042～AC-047。
- 技术设计影响：新增交互状态模型、反馈归属、格式化边界、轮询生命周期、Dialog/Drawer 可访问性和信息架构规则。
- 代码影响：`fons4ai-rag2okf-ui/src` 下交互基础组件、格式化工具、认证/资料/设置、模型设置、知识库/文档页面、应用外壳和样式。
- 测试影响：扩展 Vitest 与 Playwright，覆盖重复提交、局部错误、分页总数、搜索空态、轮询启停、焦点路径、取消清理敏感字段和三主题响应式回归。
- 接口/契约影响：无。继续使用现有 `R<T>`、`PageResponse`、文档任务与模型设置接口；当前列表搜索仅作为当前页筛选明确呈现，不伪造服务端全量搜索。
- 权限/安全影响：不改变权限和认证边界；前端加强 API Key 取消清理、条款显式同意和费用提示，不持久化密码、API Key 或会话令牌。
- 兼容/回滚影响：前端同版本回滚；不涉及数据迁移。抽取共享组件时保留页面路由、API 入参与业务动作名称。

## 6. 技术设计影响

- API/RPC/消息影响：不适用，复用现有前端 API 客户端和公共响应契约。
- 领域对象/业务规则影响：不适用，不改变文档、解析、发布、模型和认证规则。
- 状态流转影响：仅新增前端视图状态 `idle -> dirty -> validating -> submitting -> success|fieldError|formError|conflict`；业务状态机不变。
- 事务/一致性影响：不适用，前端只保证单操作提交锁和响应归属；后端幂等与 CAS 仍是最终一致性边界。
- 工具包/依赖影响：优先使用 Vue 现有能力和浏览器 `Intl`；不新增 UI 框架。上传进度如现有 HTTP 封装无法可靠提供，仅显示文件校验与提交中状态，不虚构百分比。
- UI 设计确认：已确认。视觉延续 V4 与现有主题 token；取消无真实顺序的 `01/02/03` 装饰编号，处理轨迹只在能够反映真实任务状态时展示。

## 8. 回归与回滚

- 回归风险：共享组件重构导致原提交动作失效；轮询竞态或定时器泄漏；分页后筛选语义混淆；抽屉焦点锁影响嵌套控件；主题预览与已保存偏好不一致；敏感输入残留在响应式状态。
- 回归验证范围：登录/注册、个人资料、偏好、知识库设置、模型连接与档案、知识库列表、文档目录/上传/详情、应用外壳、三主题和移动端。
- 回滚方案：按任务维度回退共享组件与页面接入提交；由于 API、路由和数据结构不变，可恢复上一前端构建。
- S2 风险门禁：敏感字段零持久化与取消清理、重复提交、Dialog 键盘路径、轮询终止/卸载清理、三主题关键 E2E 必须通过。
