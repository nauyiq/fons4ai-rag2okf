# T032 模型设置 UI 增量方案

> **状态**：已通过
> **来源**：CR-008、CR-009；技术设计说明书 §9.1；UI 设计文档 §5.5
> **依赖**：T002（UI Gate 已通过）

## 1. 主从布局

模型设置页面采用"连接在左、模型档案在右"的主从布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 模型设置                                      ＋ 添加连接     │
│ 管理你自己的模型账户；调用费用由对应厂商账户承担              │
├──────────────────────┬───────────────────────────────────────┤
│ Provider 连接        │ 当前连接：阿里云百炼                   │
│ ● 阿里云百炼         │ Base URL  https://...                  │
│ ○ 火山方舟           │ API Key  已配置 ····7K2M  [替换]      │
│ ○ 自定义             │ 最近测试  成功  2 分钟前               │
│                      ├───────────────────────────────────────┤
│                      │ 模型档案                               │
│                      │ 文本模型      qwen-plus      已验证     │
│                      │ 向量化模型    text-embedding-v3 待测试 │
└──────────────────────┴───────────────────────────────────────┘
```

* 左侧为 Provider 连接列表，点击切换右侧详情

* 右侧展示当前连接信息（Base URL、API Key 掩码、测试状态）和模型档案区

* 空状态引导用户先添加 Provider 连接

## 2. 五类模板

"添加连接"时先选择模板，预填厂商名称和常见 Base URL，不自动填模型名：

| 模板                    | providerCode     | 预填 Base URL                                         |
| --------------------- | ---------------- | --------------------------------------------------- |
| 阿里云百炼                 | ALIBABA\_BAILIAN | <https://dashscope.aliyuncs.com/compatible-mode/v1> |
| 火山方舟                  | VOLCENGINE\_ARK  | <https://ark.cn-beijing.volces.com/api/v3>          |
| 腾讯混元                  | TENCENT\_HUNYUAN | <https://api.hunyuan.cloud.tencent.com/v1>          |
| 智谱 BigModel           | ZHIPU\_BIGMODEL  | <https://open.bigmodel.cn/api/paas/v4>              |
| OpenAI-compatible 自定义 | CUSTOM           | （空，用户填写）                                            |

* 用户可根据地域或专属 Workspace 修改预填的 Base URL

* 模板只预填，不暗示自带模型或免费额度

## 3. Base URL / API Key 表单

### 新建连接

| 字段       | 类型  | 说明                      |
| -------- | --- | ----------------------- |
| 模板       | 选择  | 五类模板之一                  |
| 厂商名称     | 文本  | 预填，可修改                  |
| 连接名称     | 文本  | 用户自定义显示名                |
| Base URL | URL | 预填，可修改                  |
| API Key  | 密码  | 必填，`autocomplete="off"` |

### 编辑连接

* Base URL、连接名称可修改

* API Key 区域显示"已配置 ····7K2M"和"替换 Key"按钮

* 点击"替换 Key"打开输入框，输入新 Key 后保存

## 4. 只替换不回显

* API Key 只在新建和"替换 Key"时输入

* 保存后固定显示"已配置" + 掩码（如 `····7K2M`）+ 更新时间

* **不提供显示原值按钮**

* **不提供复制原值按钮**

* 编辑连接时 API Key 输入框为空，提交空值不修改已有 Key

## 5. CHAT / EMBEDDING 档案

每种连接可创建多个模型档案，分为两类：

| 档案类型  | modelType | 必填字段      | 可选字段      |
| ----- | --------- | --------- | --------- |
| 文本模型  | CHAT      | 档案名称、模型名称 | 超时秒数、温度   |
| 向量化模型 | EMBEDDING | 档案名称、模型名称 | 向量维度、超时秒数 |

* 每个档案有独立的状态（ACTIVE/DISABLED）和最近测试状态

* 档案列表展示：类型 · 模型名 · 状态 · 最近测试 · \[测试模型] 按钮

## 6. 测试费用提示

"测试模型"按钮附近显示提示文字：

> 会向模型厂商发送固定测试文本，可能产生少量费用。

测试结果使用用户语言：

| 结果状态         | 展示文案               |
| ------------ | ------------------ |
| 成功           | 成功                 |
| 认证失败         | 认证失败，请检查 API Key   |
| 地址不可用        | 地址不可用，请检查 Base URL |
| 模型不存在        | 模型不存在，请检查模型名称      |
| 能力不匹配        | 能力不匹配，该模型不支持当前操作   |
| 超时           | 测试超时，请稍后重试         |
| 自定义地址被安全策略拒绝 | 该地址不符合服务端出站安全策略    |

* 不暴露内部 IP 解析、DNS 判断或异常栈

## 7. 知识库按用途绑定模型

知识库设置页使用"模型用途绑定"分组：

```
┌──────────────────────────────────────────────────────────────┐
│ 模型用途绑定                                                 │
├──────────────────────────────────────────────────────────────┤
│ 回答生成    [选择文本模型档案 ▼]    qwen-plus · 已验证        │
│ 向量化      [选择向量化模型档案 ▼]  text-embedding-v3 · 待测试 │
└──────────────────────────────────────────────────────────────┘
```

* P0 展示"回答生成"和"向量化"两行

* 每行选择一个兼容档案

* 选择框只展示：档案名 / 厂商 / 模型名 / 最近测试状态

* **不展示 Base URL 全路径或 API Key**

* 不兼容该用途的模型档案不可选并说明原因（如"向量化用途需要 EMBEDDING 类型档案"）

* 配置缺失或停用时显示"请先完成模型设置"，不偷偷切换到系统默认模型

## 8. 未来用途扩展表现

* 后续增加重排（RERANK）、文档理解（DOCUMENT\_UNDERSTANDING）或 OKF 提取（OKF\_EXTRACTION）时，只需在用途绑定区追加一行

* **不改变知识库基础表单结构**

* 新增用途必须同时提供模型类型、Client Adapter 和兼容矩阵

* 用途使用受控应用枚举，不设数据库 CHECK 约束

## 9. 三主题和响应式状态

### 三主题

| 主题   | data-theme | 说明                             |
| ---- | ---------- | ------------------------------ |
| 亮色   | light      | 默认亮色                           |
| 暗色   | dark       | 暗色背景                           |
| 跟随系统 | system     | 根据 `prefers-color-scheme` 自动切换 |

* 亮暗主题保持同一信息层级和状态语义

* 状态使用图标/形状/文字，不以颜色作为唯一信息

* 用户可在"个人偏好"页切换主题

### 响应式

| 断点       | 布局调整              |
| -------- | ----------------- |
| ≥ 1180px | 左右双栏，完整展示         |
| < 1180px | 左侧面板收窄，右侧保持       |
| < 760px  | 单栏布局，连接列表折叠为下拉/抽屉 |

## 10. 安全约束清单

* API Key 无显示原值按钮

* API Key 无复制原值按钮

* 浏览器存储和 DOM 快照无 API Key

* 错误提示不展示内部 IP/URL 解析和异常栈

* 不暗示模板自带模型或免费额度

* 不展示 Sa-Token、Redis 等技术名词

* 配置缺失时 fail-closed，不静默回退到系统默认
