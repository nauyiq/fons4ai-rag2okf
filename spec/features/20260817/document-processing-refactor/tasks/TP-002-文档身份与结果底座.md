## 1. 任务包目标

- 可感知交付结果：建立 3 表目标数据结构（`kb_document`/`kb_document_result`/`kb_processing_task`）、MinIO source 对象写入、普通上传、批量上传、文档列表、详情与源文件下载能力；管理员上传文件后系统能为每个文件创建独立文档并按需冻结解析任务快照。
- 包含范围：执行型 DDL 草案与执行确认、SQL 知识快照同步；`KbDocument`/`KbDocumentResult`/`KbProcessingTask` 实体、Mapper 与 DomainService；source 制品 MinIO 存储服务；上传预检、幂等、`processingMode` 语义与 PARSE 任务创建；文档列表/详情/下载新契约。
- 不包含范围：PARSE 任务执行（解析器调用、ParsedDocument 生成）、分块、发布、删除业务与清理执行、页面适配、旧表 DROP 与旧链路退出（归 TP-003～TP-008）。
- 外部前置条件：DDL 草案由用户/DBA 审核执行（T013 外部 Gate）；本包代码验证不依赖真实数据库（延续现有 Mockito 单测基线）。
- 完成层级：Integration
