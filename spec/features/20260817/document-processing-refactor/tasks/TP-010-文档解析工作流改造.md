## 1. 任务包目标

- 建立官方页级 OCR 与页级探测，消除解析阶段按空行分块，并将 ParsedDocument 与 ChunkManifest 的产生拆为独立工作流。
- ITER-001：ParseRecognizer 仅依据上传预检的文件事实产生意图和唯一 Parser 路由；PDF 页级 probe 归 PDF 策略；MinIO 源文件以可重复打开的 InputStream 进入策略和 OCR，不对外暴露 Path。
- ITER-002：分块优先调用 Fons4AI 的 LangChain4j splitter；递归重叠、Markdown 标题和父子分块不得在 Rag2OKF 复制 SDK 算法。Rag2OKF 只负责从 ParsedDocument 映射来源 Metadata、将 TextSegment 映射为可追溯 ChunkManifest，以及保留语义分块的模型快照边界。
- TP-004 已 superseded；TP-010 实施完成并经确认后，TP-005～TP-008 按新基线重校准。
