## 1. 变更摘要

- 用户诉求：将解析、分块解耦；Rag2OKF 经 Fons4AI 接入 `paddleocr-official` 后消费页级 Markdown/图片 URL 结果；TP-004 废弃，并生成 TP-010 作为后续基线。
- 本次变更结论：新增独立 Change Task Pack TP-010；PARSE 只产出不可变 ParsedDocument，CHUNK/RECHUNK 独立产出 ChunkManifest。
- 不变更的影响：已完成 TP-001、TP-002、TP-009 保持有效；发布、删除和 UI 的未批准任务包暂不实现。

## 2. 路由与基线判断

- 现有基线状态：in-progress，TP-004 已 superseded。
- 路由结果：当前 Feature CR。
- 路由理由：改造仍属于同一文档生命周期，TP-005～TP-008 需消费新解析/分块制品，分拆为新 Feature 会割裂既有 Task Pack 依赖。
- 是否命中体量阈值：是，核心解析流程、任务制品与多后续包前置条件重构，采用独立 Change Task Pack。
- 新 Feature/继任 Feature：不适用。
- DependsOn：TP-001、TP-002、TP-009。
- Supersedes：TP-004。
- 用户决定：approved，用户于 2026-08-28 确认先生成 TP-010。

## 3. 当前状态检查

- 未完成任务或 Task Pack：TP-005～TP-008 draft/pending，待 TP-010 完成后重校准；TP-004 已 superseded。

## 4. 影响范围

- 需求影响：REQ-007、BR-009 和 AC-013～AC-014 改为独立解析/分块语义，新增 AC-035～AC-040；AC-038 只要求官方页级 Markdown/图片 URL 与 `PAGE` 锚点。
- 技术设计影响：新增 D-016、D-017；D-006 仅保留历史，不得用于新实现；D-017 使用 `paddleocr-official` 页级结果，不伪造区域字段。
- 代码影响：解析器、OCR Gateway、规范化、任务执行器、分块流程、制品与测试。
- 测试影响：有。BehaviorChange: changed；ExistingCoverage: partial；TestAction: update/add；TestLevel: unit/integration/manual；RegressionScope: affected。
- AffectedTests：BuiltInDocumentParserTest、BuiltInCapabilityPlannerTest、ParsedDocumentNormalizerTest、DocumentParseApplicationServiceTest 及新增 OCR/分块工作流测试。
- 接口/契约影响：有，内部解析任务、制品阶段和预览语义变化；OcrGateway 只返回 engine、version、有序页 Markdown 与图片 URL，`PAGE` 锚点由后续 Normalizer 映射。
- 权限/安全影响：有，OCR 凭据、源正文与对象键不得写入快照、日志或错误；OCR 服务只通过受控内部协议调用。
- 兼容/回滚影响：新工作流显式开关接管新任务；TP-004 保持 superseded，保留既有制品和历史任务。
