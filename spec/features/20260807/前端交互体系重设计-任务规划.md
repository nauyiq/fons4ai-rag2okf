## CR-001（2026-08-08）兼容说明与停止任务

### 变更背景

用户明确要求采用 **Ragflow 交互方式**，模型域还原为"**提供商 + 模型**"的两张表配置（而非原 V1.3 决策的合并单表）。添加模型提供商只需配置 **URL / API Key / 显示名** 三个字段。页面为**左右双栏**：

- **左侧上方**：默认模型配置（7 类型下拉，存个人偏好 preferenceJson.defaultModels）
- **左侧下方**：按提供商分组，展示每个提供商已添加的模型
- **右侧**：模型市场（搜索框 + 8 类型标签 + Provider 卡片网格，点击整张卡触发添加）
- **顶部账号菜单**：点击"设置"直接进入设置页，默认激活「模型提供商」Tab
