### T004
- **RED**：编写 `useTaskPolling.spec.ts`（12 个用例），覆盖首次轮询 2s、×1.5 退避、15s 上限、SUCCEEDED/FAILED 终态停止、onUpdate 回调、undefined 不回调、单飞、stop()、多次 start() 防重复、卸载清理、自定义参数。运行测试确认失败（模块不存在）。
- **GREEN**：实现 `useTaskPolling.ts`：
  - `scheduleNext()`：检查 running && isActive，安排 `setTimeout(poll, currentInterval)`。
  - `poll()`：检查 inFlight（单飞跳过）→ 检查 isActive → 执行 fetcher → onUpdate → 检查 isActive → 递增 `currentInterval = min(current * backoffFactor, maxIntervalMs)` → scheduleNext。
  - `start()`：防重复（`if (running) return`），重置 currentInterval。
  - `stop()`：running = false，clearTimer。
  - `onBeforeUnmount`：仅在 `getCurrentInstance()` 时注册，避免非组件环境警告。
- **REFACTOR**：自检 DDD-lite（轮询策略封装在 composable，视图只消费回调）、无内存泄漏（定时器+监听器清理）、退避系数/上限可配置、单飞防止重复请求。无需额外修改。
