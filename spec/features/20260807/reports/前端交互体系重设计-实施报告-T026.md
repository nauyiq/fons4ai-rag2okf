## 4. 核实结论（实现已到位）

### 4.1 /model-catalog 只读接口（AC-026）

- `controller/ModelCatalogController.java`：`GET /model-catalog` → `R<ModelCatalogResponse>`，委托 `ModelCatalogApplicationService`，符合统一响应封装。
- `application/model/ModelCatalogApplicationService.java`：
  - 从 `classpath:model-catalog.yaml` 加载厂商与模型清单；
  - **10 分钟本地缓存**：`CACHE_TTL_MILLIS = 10 * 60 * 1000L`，`volatile` 快照 + `synchronized` 双重检查锁，单例加载，不频繁读文件；
  - 返回 `ModelCatalogResponse(providers, typeCounts)`，`typeCounts` 按 `modelType` 统计模型数量。
- `common/response/ModelCatalogResponse.java`：record，含 `providers: List<CatalogProvider>` 与 `typeCounts: Map<String, Integer>`；嵌套 `CatalogProvider(providerCode, providerName, defaultBaseUrl, officialUrl, models)` 与 `CatalogModel(modelName, modelType)`。
- `resources/model-catalog.yaml`：含 4 个 provider：
  - `ALIYUN_DASHSCOPE`（通义千问）：qwen-plus(LLM) + text-embedding-v2(EMBEDDING)
  - `DEEPSEEK`：deepseek-chat(LLM) + deepseek-v3(LLM)
  - `OPENAI`：gpt-4o(LLM) + text-embedding-3-small(EMBEDDING)
  - `CUSTOM`（自定义按钮入口）：models 为空
  - 满足"3+ 常见厂商模板"Done 标准。

### 4.2 7 枚举白名单（AC-027）

- `common/constants/ModelType.java`：枚举 8 值，其中 7 个有效白名单 `LLM, EMBEDDING, RERANK, TTS, ASR, VLM, OCR`，外加旧值 `CHAT`（仅读取兼容）。
  - `whitelist()` 返回 7 值列表（不含 CHAT）；
  - `isValid(value)` 判断是否在白名单内（CHAT 返回 false）；
  - `normalize("CHAT")` 返回 `"LLM"`，其他值原样返回；
  - `@EnumValue` 标注 `value` 字段供 MyBatis-Plus 持久化。
- 常量类一处维护三处引用：档案写入校验、binding 兼容校验、前端文档参考，CHAT 拒写白名单唯一入口。

### 4.3 写入校验拒绝 CHAT（AC-027 第2点）

- `application/model/ModelConfigurationApplicationService.validateProfileInput(...)`：
  - `if (modelType == null || !ModelType.isValid(modelType.getValue())) throw new ModelConfigurationException();`
  - `ModelType.isValid("CHAT")` 返回 false → 抛 `ModelConfigurationException` → 经统一异常端点映射为 **400 BadRequest**；
  - `createProfile` 与 `updateProfile` 均调用 `validateProfileInput`，写入入口唯一校验。

### 4.4 读取 DTO CHAT→LLM 别名（AC-027 第3点 / AC-031）

- `ModelConfigurationApplicationService.toProfileResponse(...)` 调用 `normalizeResponseType(profile.getModelType())`：
  - `normalizeResponseType` 调用 `ModelType.normalize(modelType.getValue())`，CHAT→LLM；
  - 别名转换在 Response DTO 层统一做，不散落各 Controller 手写 if；
- `invokeMinimalProbe(...)` 同样调用 `ModelType.normalize` 做探活路由兼容；
- `ModelProfileResponse.modelType` 字段类型为 `ModelType` 枚举，读取旧数据 CHAT 时返回 `ModelType.LLM`。

### 4.5 binding 写入拒绝 usage_type=CHAT（AC-031 第4点）

- `common/constants/ModelUsageType.java`：枚举仅 2 值 `ANSWER_GENERATION`(要求 LLM)、`EMBEDDING`(要求 EMBEDDING)，**无 CHAT 值**。
- `common/request/ModelBindingItem.java`：`usageType` 字段类型为 `ModelUsageType` 枚举。
- 提交 `usage_type="CHAT"` 时，Jackson 枚举反序列化失败 → Spring 默认返回 **400 BadRequest**（枚举类型天然白名单）。
- `common/dto/ModelUsagePolicy.isCompatible(...)`：读取兼容旧值 CHAT（`ModelType.normalize` 归一为 LLM 后比较），保证历史 binding 仍可用。
- `KnowledgeBaseApplicationService.saveModelBindings` → `requireOwnedActiveCompatibleProfile` 调用 `modelUsagePolicy.isCompatible` 校验用途与能力匹配。

## 10. 长期知识影响

- **ModelType 7 白名单为唯一权威来源**：后续新增模型能力类型须在此枚举 + `whitelist()` 同步登记，避免散落硬编码。
- **CHAT 为废弃读取别名**：仅 `normalize` 兼容路径引用，禁止新写入；新代码不得再产出 CHAT。
- **/model-catalog 为前端 Provider/模型下拉唯一数据源**：10min 服务端缓存，前端可叠加 localStorage 缓存（30min 可配），避免频繁读 YAML。
- **binding usage_type 白名单由 `ModelUsageType` 枚举天然保证**：新增用途须扩展枚举并在 `ModelUsagePolicy` 登记兼容矩阵。
