# 金融演示语料与 20 个 Smoke 用例设计

> 状态：候选方案，等待确认。本语料中的机构、产品、规则、额度、利率条件和流程全部为虚构测试数据，不代表任何真实金融机构或授信政策。

## 1. 设计目标

首批语料不是追求文档数量，而是构造一组能够同时验证以下能力的受控事实环境：

- PDF、DOCX、Markdown、TXT 的结构化解析；
- 标题、列表、表格、跨页表格和 SourceAnchor；
- 文档版本、政策生效日期和过渡期；
- BM25、向量、混合检索和 Rerank；
- 单文档、跨文档、多跳和对比问题；
- OKF 概念、关系、来源绑定和跨文档合并；
- 无答案、越界问题和真实授信决策拒答；
- 历史 PublicationRevision 引用。

## 2. 虚构业务背景

演示机构统一使用：

```text
机构：云帆普惠（虚构）
知识库：小微企业贷款制度库
KnowledgeBaseId：kb-yunfan-sme-loan
当前语料版本：FIN-CORPUS-V2
币种：人民币
```

三个虚构产品：

| 产品 | 定位 | 是否抵押 |
|---|---|---|
| 启航经营贷 | 面向经营稳定的小微企业流动资金贷款 | 否 |
| 税信快贷 | 基于企业纳税信息的信用贷款 | 否 |
| 安业抵押贷 | 以符合条件的经营性房产作为抵押 | 是 |

使用边界：

- 知识库只解释产品和制度，不执行授信审批；
- 不接收真实身份证号、征信、银行流水或客户隐私；
- “符合某条规则”不等于“最终可以获批”；
- 不回答知识库没有覆盖的市场预测、实时利率和监管结论。

## 3. 受控事实字典

事实字典是生成演示文档和标注黄金答案的唯一业务基准。文档可以采用不同表述，但不能擅自改变这些事实。

### 3.1 启航经营贷

| 事实 | 当前规则 |
|---|---|
| 金额 | 10 万～200 万元 |
| 期限 | 12、24 或 36 个月 |
| 用途 | 合法生产经营周转 |
| 抵押 | 不要求房产抵押 |
| 借款人年龄 | 申请日 23～58 周岁，含边界 |
| 企业持续经营 | 不少于 24 个月 |
| 实际控制人持股 | 不低于 20% |
| 基础材料 | 身份证明、营业执照、近 12 个月经营流水、纳税记录、贷款用途声明 |
| 条件材料 | 申请金额超过 100 万元时补充主要购销合同 |

历史 V1 规则：借款人年龄为 22～60 周岁。V2 自虚构日期 `2026-04-01` 起生效。

### 3.2 税信快贷

| 事实 | 当前规则 |
|---|---|
| 金额 | 5 万～100 万元 |
| 期限 | 12 或 24 个月 |
| 抵押 | 信用方式，不要求抵押物 |
| 企业持续经营 | 不少于 18 个月 |
| 纳税连续性 | 最近连续 12 个月有申报记录 |
| 纳税信用等级 | A、B 或 M |
| 基础材料 | 身份证明、营业执照、税务数据授权书、经营账户流水、贷款用途声明 |

### 3.3 安业抵押贷

| 事实 | 当前规则 |
|---|---|
| 金额 | 50 万～500 万元 |
| 期限 | 12～60 个月 |
| 企业持续经营 | 不少于 12 个月 |
| 抵押物 | 符合条件的经营性房产 |
| 最高抵押率 | 评估价值的 70% |
| 特有步骤 | 贷前调查后、授信审批前完成抵押物评估 |

### 3.4 共用审批与版本规则

| 授信金额 | 审批机构 |
|---|---|
| 不超过 50 万元 | 分支机构高级审批人 |
| 超过 50 万元且不超过 200 万元 | 区域审批中心 |
| 超过 200 万元 | 总部审批委员会 |

启航经营贷年龄规则的过渡安排：

- `2026-04-01` 及之后提交的新申请使用 V2；
- `2026-04-01` 前提交且已经通过预审的申请，可在 `2026-05-31` 前继续按 V1 的年龄规则处理；
- 过渡安排只影响年龄规则，不代表申请整体获批。

通用申请流程：

```text
提交申请
→ 完整性预检
→ 数据授权
→ 贷前调查
→ 抵押物评估（仅抵押产品）
→ 授信审批
→ 合同签署
→ 放款
```

### 4.2 格式与结构分布

```text
PDF       7 份：表格、页码、区域高亮、版本通知
DOCX      5 份：标题、列表、流程和条件材料
Markdown  3 份：目录、FAQ、术语和链接
TXT       1 份：简单边界规则
```

首轮不把扫描 PDF 纳入正式支持集，仅准备一个额外样本用于 TV-02 判断 P0 是否需要 OCR。

## 5. 文档内部结构蓝图

每份文档至少包含：

```text
文档标题
文档编号
版本号
生效日期
适用范围
正文分节
相关文档
修订记录
“虚构演示材料”页脚或声明
```

### 5.1 有意设置的检索难点

- 产品总览和产品说明重复出现额度，但详细规则文档具有更高证据等级；
- FAQ 使用口语表达，制度文件使用正式术语；
- FIN-004 V1/V2 同时保留，只有 V2 是当前活动版本；
- FIN-015 解释过渡期，需要与 FIN-004 V1/V2 联合回答；
- FIN-011 使用金额区间表，包含 50 万和 200 万边界；
- FIN-005 把“超过 100 万”条件材料放在独立小节；
- FIN-009 的抵押率不能被错误解释为贷款获批概率；
- FIN-001 与 FIN-016 明确限制真实授信决定和实时预测。

### 5.2 SourceAnchor 命名

设计阶段使用可读锚点：

```text
FIN-004@V2#eligibility.age
FIN-005@V1#materials.conditional.contracts
FIN-010@V2#process.collateral-appraisal
FIN-011@V1#approval-matrix.row-2
FIN-015@V1#transition.before-effective-date
```

实际实现时，锚点还需保存页码、Block ID、区域坐标和内容快照。

## 6. OKF 预期覆盖

### 6.1 预期核心概念

| 类型 | 首批概念示例 |
|---|---|
| Product | 启航经营贷、税信快贷、安业抵押贷 |
| Policy | 启航经营贷准入规则、抵押管理规则、政策变更通知 |
| Eligibility Rule | 年龄要求、经营期限、持股比例、纳税连续性、纳税等级、抵押率 |
| Procedure | 贷款申请流程、抵押物评估、授信审批 |
| Material | 营业执照、经营流水、税务数据授权书、购销合同 |
| Definition | 预审、授信、抵押率、实际控制人 |

### 6.2 预期关系示例

```text
启航经营贷 REQUIRES 身份证明
启航经营贷 APPLIES_RULE 年龄要求
税信快贷 REQUIRES 税务数据授权书
安业抵押贷 REQUIRES 抵押物评估
抵押物评估 PRECEDES 授信审批
政策变更通知 SUPERSEDES 启航经营贷准入规则 V1 的年龄条款
审批权限矩阵 GOVERNS 三个贷款产品
```

V1 与 V2 的年龄规则不能被去重成一个无版本概念。合并建议必须保留生效区间和来源。

## 7. 20 个 Smoke 黄金用例

证据等级约定：`P` 表示主要证据，`S` 表示辅助证据。

### 7.1 精确事实与限额

| ID | 问题 | 期望证据 | 必须包含 | 禁止结论 |
|---|---|---|---|---|
| SMK-001 | 启航经营贷最高可以申请多少？ | P: `FIN-003@V2#product.amount` | 最高 200 万元 | 500 万元 |
| SMK-002 | 当前启航经营贷对借款人年龄有什么要求？ | P: `FIN-004@V2#eligibility.age`；S: `FIN-015@V1#change.age` | 申请日 23～58 周岁，含边界 | 22～60 周岁是当前规则 |
| SMK-003 | 启航经营贷要求企业至少经营多久？ | P: `FIN-004@V2#eligibility.business-age` | 不少于 24 个月 | 18 个月 |
| SMK-004 | 税信快贷最长贷款期限是多少？ | P: `FIN-006@V1#product.term` | 24 个月 | 36 个月 |

## 9. 语料制作与标注顺序

```text
冻结事实字典
→ 编写 16 份源文件
→ 人工检查跨文档一致性
→ 建立 DocumentVersion 和生效关系
→ 解析并生成 SourceAnchor Manifest
→ 标注 Evidence Judgment
→ 标注 Required/Forbidden Claims
→ 运行 BM25 Baseline
→ 才允许开始调参
```

必须先冻结答案和证据，再运行候选模型。不能根据模型现有输出反向修改黄金标签。

## 10. 数据安全规则

- 人名、企业、证件号、联系方式、账户和征信记录全部使用虚构数据；
- 不复制公司内部制度、客户材料或生产提示词；
- PDF 元数据、作者和文件路径也不能带入公司信息；
- 每页添加“虚构演示材料，不构成金融建议”；
- Git 仓库只保存可以公开展示的样本；
- 未来如使用公开政策，只引用公开来源并记录许可证与抓取日期。

## 11. 本阶段确认门

进入样本文档内容设计前，需要确认：

1. 是否接受“云帆普惠”及三个虚构产品；
2. 是否接受 16 个 SourceDocument、17 个 DocumentVersion 的规模；
3. 是否接受启航经营贷 V1/V2 年龄变更和过渡期案例；
4. 是否接受首批 20 个 Smoke 用例全部作为 DEV；
5. 是否接受真实授信决策和市场预测必须拒答；
6. 是否允许下一步只生成“文档内容规格与模板”，仍不生成正式业务代码。
