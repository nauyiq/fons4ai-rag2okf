## 1. 项目简介

- 项目定位：可追溯、可观察的企业知识库与知识工程平台，提供文档工程、RAG 混合检索、OKF 知识工程和企业级知识管理能力。
- 核心业务线：知识库管理、文档工程（上传/解析/分块/发布）、OKF 知识工程（概念提取/Bundle 发布）、RAG 混合检索与引用问答、用户与认证。
- 主要使用方：知识管理员（创建/配置/上传/解析/发布/OKF 构建）、知识用户（问答/查看引用/反馈）。
- 当前知识可信度：产品设计和 SDD 已建立，后端/前端已有实现候选；用户域已完成深度建模，其他领域待建模。
- 基线确认摘要：项目类型=业务系统；定位=企业知识库与知识工程平台；5 领域（知识库域/文档域/OKF 域/检索域/用户域）；标准流程=知识库文档生命周期。
